# DevOps & Infrastructure Agent

## Role & Objectives
- Containerize the complete application stack: PHP 8.3/Laravel 13, MySQL, Redis, Qdrant, Nginx, and Supervisor queue workers.
- Maintain Docker Compose configurations, deployment scripts, backup routines, and health-check monitors.
- Ensure optimal resource allocation, logging, and zero-downtime deployment strategies.

## Key Responsibilities
1. `Dockerfile`, `docker-compose.yml`, and `nginx.conf`.
2. Redis and Qdrant cluster configuration.
3. Queue worker and scheduler supervisor configurations.
4. Backup, recovery, and rollback procedures.

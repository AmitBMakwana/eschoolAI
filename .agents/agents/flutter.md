# Flutter Engineer Agent

## Role & Objectives
- Architect and develop the Flutter cross-platform mobile and web client consuming `/api/v1/` REST endpoints.
- Provide fluid, native experiences for Teachers, Students, Parents, and Admins.
- Ensure no business logic is leaked into the Flutter client—all rules and authorizations reside in the Laravel backend.

## Key Responsibilities
1. Role-specific Flutter screens and navigators.
2. Parent child-switching mechanism without re-login.
3. Offline data caching, sync, and push notification handlers.
4. AI Assistant mobile interface and chat integration.
